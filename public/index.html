How it decides

A persistent agent calls two independent, real Telegraph signals for each policy's location — a weather forecast and a storm alert — paid on-chain via x402. It only triggers when both corroborate, both clear a calibrated confidence threshold, and both agree on the same location.

What the network actually returns

Telegraph routes by intent, so which miner answers is a ranking decision — and ranking is meant to move. We measured what that means for an application: 24 auto-routed, x402-paid calls across 12 cities on five continents.

So the schema an application receives is a property of the network at call time, not a fixed contract — and a reader bound to one shape keeps returning 200 OK while quietly finding nothing. StormPolicy derives severity from whichever representation is present: probability, millimetres, an m/s series, risk flags, official alerts, a threshold breach, or prose. Skin in the game

An agent that can move money should have something to lose when it's wrong. In the bonded contract the agent stakes a bond behind its claim instead of paying out directly — anyone can dispute by matching that bond, and the loser's stake goes to the winner.

  1. Assert The agent stakes a bond and submits its evidence. No funds move yet.
  2. Dispute window Anyone can challenge by matching the bond.
  3. Finalize Unchallenged, anyone can release the payout; the bond returns.
  4. Arbitrate If challenged, an arbiter rules and the loser's bond pays the winner.
Verified on Base Sepolia — 25/25 tests passing
undisputed      -> payout released, bond returned
disputed, agent right -> payout released, agent takes disputer's bond
disputed, agent wrong -> no payout, agent's bond slashed to disputer

Value conservation checked exactly, including the OP-stack L1 data fee.

Create a policy

Cover for one place, funded up front and settled by the agent rather than by a claim. You escrow an amount now; if corroborated storm conditions hit that location, exactly that amount is released to whoever you name. If they never do, you take it back.

  1. 1You escrow an amount. It sits in the contract, visible on-chain. Nobody, including us, can spend it on anything else.
  2. 2The agent watches your location against two live Telegraph signals, on a schedule, without being asked.
  3. 3It releases or it doesn't. Corroborated storm conditions send the full amount to the beneficiary. Otherwise you cancel and reclaim it whenever you like.
A city the forecast and alert signals can both resolve. Storm-exposed places are the realistic case — Manila, Cebu, Taipei, Miami, Okinawa, Dhaka.
This is test ETH on Base Sepolia, not real money. The whole amount is what gets paid out — there is no premium and no partial settlement. Small values are fine; the standing book uses 0.000002 ETH per city.
Filled with your own address when you connect. Change it if the cover is for someone else.
